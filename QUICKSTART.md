# Quick Start

## Prerequisites

- Python 3.10+
- Node.js 18+

## 1. Run the intelligence pipeline

This is the step that matters: it generates the synthetic merchant
ecosystem and runs all three engines, fusion, loss-event detection,
counterfactual simulation, and the AI investigator. The backend serves
this output rather than recomputing it, so it must run first (and again
any time you change anything under `data/generation/` or `ml/`).

```bash
pip install -r backend/requirements.txt
make pipeline
```

Takes about 10-15 seconds. Produces `data/output/` and `ml/artifacts/`
(both gitignored -- regenerate, don't expect them in a fresh clone).
Prints a summary as it goes; `ml/README.md` and `docs/EVALUATION.md`
explain what the numbers mean.

Optionally, `export ANTHROPIC_API_KEY=sk-ant-...` first for real
Claude-generated investigation narratives -- without it, the pipeline
automatically falls back to deterministic evidence-chain summaries (no
error, this is intended behavior, see `docs/ARCHITECTURE.md`'s AI
Investigator section).

## 2. Start the backend

```bash
cd backend
python -m uvicorn app.main:app --reload
```

Runs on http://localhost:8000. Check http://localhost:8000/api/v1/health
or http://localhost:8000/docs (Swagger UI).

## 3. Start the frontend

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000 -- the Command Center should load real
incidents from step 1. If it doesn't, the yellow banner on the page will
say why (usually: the pipeline hasn't been run, or the backend isn't up).

## What you'll see

- **Command Center**: exposure/confidence/action metrics and a sortable
  incident table, with a merchant filter.
- Click any incident: an **AI Investigation** case-file narrative
  (labelled "Generated by Claude" or "Deterministic fallback" depending on
  whether `ANTHROPIC_API_KEY` is set), an **evidence chain** (expandable,
  evidence IDs E1/E2/...), the **entity graph** for cluster-sourced events
  (Cytoscape.js -- empty for temporal-only events like `chargeback_wave`,
  which is itself meaningful, not a bug), and the **counterfactual policy
  comparison** with the economically-recommended action highlighted.
- A **ground-truth panel** at the bottom of each incident, clearly labelled
  as evaluation-only, showing how much of what was flagged is genuinely
  the injected scenario vs. a legitimate look-alike.

## Troubleshooting

- **API routes return 503**: the pipeline hasn't been run, or was run from
  a different working directory. Re-run `make pipeline` from the repo
  root.
- **`ModuleNotFoundError`**: `pip install -r backend/requirements.txt`
  installs everything `data/generation/` and `ml/` need too (numpy,
  pandas, lightgbm, shap, networkx, scikit-learn) -- there's no separate
  requirements file for those.
- **Frontend build fails**: make sure `npm install` ran inside `frontend/`,
  not the repo root.
